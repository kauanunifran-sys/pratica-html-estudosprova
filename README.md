Esta é uma atividade complementar de estudo, o objetivo é praticar para a prova da materia de front-end, segundo semestre de ciencias da computacao. Construir, do zero, uma única página: um formulário de cadastro, aplicando semântica HTML5, formulários e seus primeiros seletores CSS. A ideia central é que o aluno escreve o codigo linha por linnha para praticar, usando os requisitos de cada etapa como guia.
